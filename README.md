 🌾 KrushiAI – Smart Agriculture Assistant
KrushiAI is an AI-powered web platform designed to support farmers with intelligent agricultural solutions. It helps in making better farming decisions using technology, data, and automation.

 🚀 Features
- 🌱 AI-based crop recommendations
- 🌍 Multilingual support (for Indian farmers)
- 📊 Soil analysis insights (future scope)
- 💬 Chatbot for farmer queries
- 📅 Seasonal crop guidance
- 📍 Location-based suggestions
